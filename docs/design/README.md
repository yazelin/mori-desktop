## 為什麼三視圖要獨立成檔

[cast-lock](https://github.com/yazelin/cast-lock-skill) 有一條：**群像設定表不可以直接當參考圖**。設計稿全張裡有三視圖、Q 版、表情集、色卡與標籤文字，整張丟進生圖模型，它會把別的視角、別的表情、甚至標籤文字一起帶進結果。要當參考圖，必須是「只有一個人、一個視角、沒有文字」的乾淨圖。

所以三視圖切成三個檔，一個視角一張。要生 Mori 的新素材時直接用這三張。

## mori-full-illustration.webp 與三視圖的來歷

設計稿裡「01. FULL ILLUSTRATION」那一格在原圖上只有 235×410，拿去做網頁的角色卡會糊，而且沒有更大的來源。

放大這條路試過不通：`realesrgan-ncnn-vulkan` 在開發機上三個 GPU index 全部吐全黑圖，退出碼還是 0。

所以改成重畫：把設計稿裁出乾淨的單人參考圖（沒有標籤文字），照 cast-lock 的做法把識別特徵與「不可以出現的東西」逐條寫死，交給生圖模型重畫，出圖後裁下來放大逐項驗收。三視圖是**一個視角生一張**，不是一次生一整排，因為一次生一排的話三隻會互相污染。

驗收項目除了識別特徵，還包含解剖：每隻手 4 指加 1 拇指、指頭分開接得到袖子，露出來的腳每隻 5 根腳趾。這幾項在全身縮圖上永遠看起來沒問題，一定要裁下來放大到看得見指甲才判。第一版的完整立繪就是這樣漏掉的，右手當時是五六個沒有指節的圓塊黏在一起。

**人與 AI 的分工**：構圖、造型、配色、氛圍全部來自既有的設計稿；重畫這一步由 AI 執行，驗收由人做。它是設計稿的衍生物，**角色正典仍然是 `mori-1.png` 與 `mori-2.png`**，兩者衝突時以設計稿為準。

用途：需要一張夠大的 Mori 立繪時直接拿這張，不必再從設計稿裁。目前用在 [blog 的角色頁](https://yazelin.github.io/characters/mori/)。
